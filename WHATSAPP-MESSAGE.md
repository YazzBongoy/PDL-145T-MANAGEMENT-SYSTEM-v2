## ⚡ Alternative rapide (ngrok) :

Si vous voulez tester **maintenant** sans déployer :

```bash
# 1. Installer ngrok
npm install -g ngrok

# 2. Démarrer l'app (si pas déjà fait)
cd frontend && npm run dev

# 3. Créer tunnel (dans un autre terminal)
ngrok http 5173

# 4. Copier l'URL https://xxx.ngrok.io
```

⚠️ Lien temporaire (2 heures max)
